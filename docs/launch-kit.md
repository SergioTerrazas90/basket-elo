# BasketElo launch kit

This is the small set of links and messages to use when introducing BasketElo. Keep the product link attached to a basketball observation, not as a standalone announcement.

## Permanent links

- Main rankings: `/`
- Biggest movers: `/movers`
- Browse by competition: `/browse`
- Methodology: `/how-it-works`
- Data sources and coverage: `/data-sources`

Team links use the shareable form `/team/{id}/{team-slug}`. The older `/teams/{id}` form remains available for compatibility.

## Campaign links

Add these query parameters to the links you publish so the server logs identify the source without adding a third-party tracker:

```text
/?utm_source=x&utm_medium=social&utm_campaign=launch
/?utm_source=reddit&utm_medium=community&utm_campaign=launch
/?utm_source=producthunt&utm_medium=launch&utm_campaign=launch
/?utm_source=apbrmetrics&utm_medium=community&utm_campaign=launch
```

Use a distinct `utm_campaign` for later recurring series, such as `acb-opening`, `nba-opening`, or `elo-movers`.

## Launch checklist

- Check the social preview by pasting the URL into X, LinkedIn, Discord, and Reddit.
- Confirm the rankings and at least two team profiles work while signed out.
- Publish one ACB or European-club data story before the general launch thread.
- Reply to comments with analysis and links to the relevant page.
- Record clicks and returning visitors, not only impressions or likes.
